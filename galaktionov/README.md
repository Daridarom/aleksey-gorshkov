# Владимир Георгиевич Галактионов — историко-биографический сайт

## Состав
- `index.html`: адаптивный сайт с 12 полнотекстовыми редакционными историями, 12 вехами хронологии, фильтрацией, поиском, повышением читаемости, фотогалереей и видеоплеером RUTUBE.
- `assets/galaktionov-portrait.webp`: оптимизированная версия фотографии, переданной пользователем.
- `assets/galaktionov-original.jpg`: исходный снимок, сохранён без редакционного изменения.
- `sources.csv`: первоисточники и пометы об использовании.

## Редакционные ограничения
- **Тексты**: собственные краткие материалы, не копии публикаций. Полные сторонние статьи и фотографии нельзя перепечатывать без согласования прав.
- **Изображения**: только предоставленный снимок. Фотоархив РИА Новости и детское фото в Некрасовском колледже открываются через источники, пока нет разрешения на воспроизведение.
- **Видео**: встраивание плеера RUTUBE по конкретной ссылке; если площадка заблокирует iframe, останется ссылка.
- **Точность**: анонс музея 26.11.2022 обозначен как анонс, а не отчёт о состоявшейся встрече.
- **Временная публикация**: noindex для предварительного просмотра; после согласования с героем снять.
- **Авторские права**: на локальную фотографию необходимо подтверждение возможности публичной публикации.

## Проверка
Открыть `index.html` в любом современном браузере. Для GitHub Pages весь каталог должен быть размещён в папке `galaktionov/` публикуемой ветки.
