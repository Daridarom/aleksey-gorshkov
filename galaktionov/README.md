# Владимир Георгиевич Галактионов — личный архив

Одностраничный историко-биографический сайт: https://daridarom.github.io/aleksey-gorshkov/galaktionov/

## Как устроено

| Файл | Что внутри |
|---|---|
| `content/site.json` | Все материалы: вступление, 7 историй жизни, хронология (3 периода), 11 встреч, фото с подписями и правами, видео, источники |
| `build.py` | Собирает `index.html` и `sources.csv` из `site.json` (Python 3, без зависимостей) |
| `index.html` | Готовая страница. Читается и без JavaScript |
| `assets/site.css`, `assets/site.js` | Оформление и удобства: увеличение фото, «Поделиться», поиск, А+/А−, контраст, печать истории |
| `assets/photos/` | Фото в двух форматах (WebP + JPEG) и при необходимости двух размерах |
| `assets/fonts/` | Шрифт Lora (лицензия SIL OFL 1.1), кириллица + латиница, один файл |
| `photos-registry.csv` | Реестр фото: кто на снимке, автор, источник, статус прав, что сделать. Включая фото на согласовании |
| `sources.csv` | Список источников (генерируется) |

## Как добавить историю или фото

1. Откройте `content/site.json`.
2. История — новый объект в `stories` (`id` латиницей станет ссылкой `…/galaktionov/#id`). Источник — ключ из `sources`.
3. Фото — положите файлы `assets/photos/<id>-<ширина>.webp` и `.jpg`, добавьте объект в `photos` с подписью, автором, источником и статусом прав. Чтобы временно скрыть снимок — `"publish": false`.
4. Запустите `python3 build.py` и откройте `index.html`.

## Редакционные правила

- Тексты — собственные пересказы, не копии статей. У каждой истории — ссылка на публикацию.
- Не публикуем непроверенное как факт: анонс 26.11.2022 помечен как анонс; год встречи в Некрасовском колледже уточняется.
- Публикация фото согласована с Владимиром Георгиевичем (подтверждено 07.11.2026). У каждого снимка — автор и первая публикация.
- Людей на фото называем только по подписи источника; неподписанных не называем.
- Реестр «Героев самопожертвования» (456 позиций) — отдельное направление, в биографию не смешивается.
- `noindex` сохранён до решения заказчика.
- Ссылки на истории старой версии (`#childhood`, `#brother`, `#officers` и др.) продолжают работать.
