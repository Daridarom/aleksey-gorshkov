# Личное цифровое пространство Алексея Горшкова

Первая рабочая версия нового личного сайта. Вместо обычного портфолио сайт построен как несколько связанных режимов:

- **Я** — короткий путь и ключевые этапы опыта;
- **Знаю** — библиотека уже прожитого и осмысленного знания;
- **Делал** — проекты как доказательство опыта;
- **Сейчас** — отдельная динамическая лента для свежих публикаций и внешних источников;
- **Ясень** — навигатор по содержанию и связям сайта.

## Архитектура

- `index.html` — структура интерфейса;
- `styles-v3-base.css` — базовая типографика, шапка, главный экран, история;
- `styles-v3-content.css` — лента «Сейчас» и библиотека;
- `styles-v3-ui.css` — карта связей, проекты, Ясень, адаптивная версия;
- `app-v3.js` — динамический рендеринг данных, фильтры, локальный поиск Ясеня;
- `content-v3.json` — библиотека знаний, проекты, этапы опыта и карта связей;
- `feed-v3.json` — содержимое динамической ленты «Сейчас»;
- `sources-v3.json` — конфигурация будущих внешних источников (VK / RSS);
- `assets/` — фотографии, фамильный знак и OG-обложка предыдущей версии сайта.

## Принцип контента

Свежий внешний поток и постоянная библиотека разделены. RSS, VK и другие источники могут попадать в раздел **«Сейчас»**, но не становятся автоматически частью **«Знаю»**. В библиотеку попадает только отобранный и осмысленный материал.

Секретные ключи и токены внешних сервисов нельзя хранить в этом публичном репозитории. Подключение VK/RSS следует делать через build-time/server-side адаптер или отдельный защищённый backend.
