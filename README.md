# Личный сайт Алексея Горшкова

Адаптивный личный сайт-портфолио об общественной деятельности, опыте,
компетенциях и проектах Алексея Горшкова.

## Что находится в репозитории

- `index.html` — содержание и структура сайта;
- `styles.css` — цвета, шрифты, расположение блоков и мобильная версия;
- `assets/portrait.webp` — главный портрет;
- `assets/portrait-mobile.webp` — облегчённый портрет для телефона;
- `assets/speaker.webp` — фотография публичного выступления;
- `assets/speaker-mobile.webp` — облегчённая версия фотографии для телефона;
- `assets/vision.webp` — визуальный акцент раздела компетенций;
- `assets/vision-mobile.webp` — облегчённая версия визуального акцента для телефона;
- `assets/og.png` — обложка сайта для социальных сетей;
- `assets/favicon.svg` — фамильный знак в форме щита с лабиринтом;
- `.nojekyll` — технический файл для корректной публикации через GitHub Pages.

Все кнопки связи на сайте ведут на публичную страницу:
`https://vk.com/aleksey_gor`. Ссылки на другие мессенджеры не используются.

## Как открыть сайт через GitHub Pages

1. Откройте вкладку **Settings** репозитория.
2. В левом меню выберите **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. После публикации сайт будет доступен по адресу:
   `https://daridarom.github.io/aleksey-gorshkov/`

## Как вносить изменения

GitHub сохраняет историю каждой версии. Чтобы изменить текст, фотографию или раздел, достаточно описать желаемый результат — новую версию можно подготовить, сравнить с предыдущей и при необходимости отменить.

## Публикация

GitHub Pages автоматически публикует изменения из ветки `main`. Обычно новая
версия появляется по адресу сайта через несколько минут после обновления.
